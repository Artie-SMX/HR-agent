# 基于 Qwen-Agent 的简历信息整理与面试问题生成助手

### 功能
- 内容：
1. 用户输入一份简历文件和目标岗位文件。
2. Agent 自主调用本地文件读取工具。
3. 提取学历、技能、项目经历、实习经历等客观信息。
4. 未写明的信息统一标记“简历未提供”，禁止猜测。
5. 根据岗位要求生成 5 个面试追问。
6. 输出 Markdown 或 JSON 格式的整理结果。
7. 不进行“录用/淘汰”判断，不给候选人打分，最终决策交给人工。

- 设计考虑：
    
    能更好贴近HR应用场景，解决流程化固定化的筛选以及追问，实现流程自动化以及结构化输出；最终人工复核环节也符合任务2案例中的真实企业实践案例。

### 技术选择
推荐主方案：
- 编程语言：Python 3.11
- Agent 框架：Qwen-Agent
- 模型服务：阿里云百炼/DashScope
- 运行方式：Windows 本地命令行
- 编辑器：VS Code
- 版本管理：Git
- 第一版界面：命令行，不做网页
- 数据：3 份虚构简历、2 份虚构岗位说明
